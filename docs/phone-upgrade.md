# 此间 3.0 使用与迁移说明

适用版本 3.0.0。数据库版本 11，备份格式 6，兼容导入旧备份 1～5。

## 先选作品模式

从故事列表或新手引导创建，第一步选择「小说模式」或「手机模式」，之后才填写名字、选择角色和世界书。模式创建后固定；列表可筛选全部、小说、手机。创建表单刷新后可继续填写。

小说保留正文、灵感、记忆、小剧场和作品导出。手机进入独立创作界面，提供角色手机、备忘录与相册、背景与知情、批量编排、阅读编排与分享。没有作品内的模式切换。

角色库与世界书库是模板，选入作品时保存副本。后续修改模板或另一作品不会自动同步。两种作品共用应用级接口配置；生成只查询当前作品。

手机开场背景可指定知情角色，作者秘密单独保存，不默认提供给模型角色。在「背景与知情」里可以添加、修改、启用或停用材料，并调整知情角色。

## 旧档自动拆分

每本没有类型的旧故事拆为《原名·小说》和《原名·手机》，空的一侧也保留。小说保留原 ID、正文及版本、正文草稿、正文回合编号与窗口、有效小说记忆、小剧场。手机获得新作品 ID 和角色副本，接收旧聊天及已存在的手机记录、附件、皮肤、联系人备注、群关系、待回复消息、会话草稿与恢复批次。

拆分时按角色原有知情权限复制全部有效小说经历及合格记忆，形成手机自己的「承接背景」。默认启用范围沿用旧正文窗口和默认记忆读取规则，不消耗一次性勾选。其余已知材料保留为未启用，作者可以查看和调整。这是一次本地复制，不调用模型，也不扩大权限；以后不再访问源小说。

历史生成已有的参考快照继续用于重写。旧任务没有快照时，只用手机自己的承接背景与当时可见记录重建，并标明恢复来源。混合聊天来源摘要、旧聊天原始记录与旧恢复资料按记录进入兼容归档，不参与新请求。

每本旧故事在一个事务里拆分，保存迁移标识与 ID 关联。重复启动不重复创建；存储不足或其他错误会回滚这本作品，原档仍保留，页面提供重试。升级被其他标签页阻塞时会提示关闭旧页面。正在另一标签页执行的任务不会被启动恢复误标为中断。

完成后显示拆分通知，可分别进入小说与手机。编辑、归档或删除一本不影响另一本。重新导入旧备份作为副本会正常拆分新副本，不合并已有作品。

## 聊天、群聊与朋友圈

「角色手机」选择机主，在联系人中打开私聊；也可以新建群聊。参与模式允许连续发送，然后点击「让 TA 回复」。编排模式可切换发言角色手写消息，或选择角色与情境，让 AI 按顺序推进。

双方手机显示同一份会话，方向、备注、置顶和皮肤按机主保存。成员变更留下系统提示；每条消息固定保留发送时受众，后来入群者看不到旧秘密。

支持文字、表情、图片、音频、语音文字、引用、撤回、剧情转账和通话卡。没有真实音频文件的语音文字卡不显示播放器。剧情时间可修改，实际创建时间独立保存；编辑、删除和恢复保留版本。删除内容退出后续参考，撤回保留故事内提示。

朋友圈支持最多九张图片、点赞、评论和回复，可设全部角色、指定角色或仅自己可见。互动受原动态受众限制，生成不能扩大可见范围。

图片及音频每个文件最大 10 MiB，图片保存前规范尺寸。附件留在本机，文本模型接收图片说明、语音文字与结构化卡片。存储失败时保留编辑内容并提示原因。

## 备忘录、相册与剧情草稿

在「备忘录与相册」中选择机主，然后新建备忘录、照片或剧情草稿。支持剧情日期、图片、置顶、编辑、删除与版本恢复；照片可分相册并查看完整图片，素材可从本作品复用。

默认仅机主知晓，也可明确授权其他角色。剧情草稿可选拟发送对象，用于表现角色写过但没发出去的话。真实编辑器的自动草稿不会自动进入剧情或阅读包。

文档密码由阅读编排中的解锁规则配置。阅读规则只限制读者探索，不改变角色知情范围。

## 批量编排

选择会话，展开「粘贴整段剧本」，按「角色名：内容」粘贴。下一行没有冒号时接在上一条消息中。重名或未知称呼必须选择角色映射，无法解析或空消息不能保存。预览确认后先保存为编排草稿，点击「采用这份编排」才写入正式记录。

可多选消息，统一调整剧情时间；拖动或点击上移、下移改变顺序。显示与后续参考使用编排顺序，稳定 ID、实际创建时间和受众不变。

「复制为对话变体」产生独立草稿，可以手改，也可以填写要求后显式生成变体。采用前不进入角色经历；采用后原稿保留为可恢复版本。操作历史可撤销整个批量操作，原记录后来修改时会阻止直接覆盖。目标会话生成期间暂缓重排和采用，仍可发送留给下一轮的新消息。

## 捡到手机与线索解锁

进入「阅读编排与分享」，设置开场文字、初始机主、锁屏密码、通知与应用顺序，勾选允许分享的手机。读者从开场就可以切换这些手机；每部手机只呈现对应角色有权看到的内容。

默认自由翻阅。切换「线索解锁与轻解谜」后可锁定整个应用，或勾选一组消息、朋友圈、备忘录、照片、剧情草稿作为内容段。未设置规则的内容直接可见。

规则可要求读过指定内容、完成另一条线索或输入答案；多个条件可选全部满足或任一满足。答案可写多个，支持作者提示、答错提示和一次性剧情通知。读者实际看到的内容才计为已读；仅打开会话不会把整段历史算作已读。

隐藏内容不会进入消息预览和引用。预览和导出前会检查缺失目标、未分享的前置材料、循环与无法到达的条件。密码只用于剧情，不加密 HTML 文件；本版不含选择分支、多结局或任意脚本。

## 聊天演出

在「聊天演出与回放」选择会话、创建演出，可移除或重排步骤、设置出现前停顿、正在输入和出现后撤回。撤回前文字只有作者明确填写收录后才进入演出。

读者可播放、暂停、调速、跳过停顿、重新播放。回放只呈现已编排内容，不调用模型或新增消息，不能跳过未解锁内容。真实音频保留手动播放入口。

## 分享、备份与导出

「选择分享内容」默认收录当前可见记录，可逐条取消。点击读者预览检查后，导出自包含 HTML。阅读器、所选素材和皮肤内嵌在文件中，断网、无账号、无 Key 也可打开。支持机主切换、应用浏览、线索、回放和重新开始。

阅读进度按包 ID 与内容版本保存；本地持久化不可用时提供进度文件导入、导出。包里不包含作者秘密、生成参考、未采用版本、编辑器草稿或未选中记录。阅读器与创作数据库分离，不能修改作品或调用 AI。

保留聊天、朋友圈的 PNG 长图及超长分图 ZIP，使用当前机主视角与皮肤。小说与手机分别导出，不再合并为正文和番外。文本作品导出侧重聊天记录；需要包含手机文档、线索和演出时使用离线阅读包。

完整备份含所有独立作品。单本备份只含该作品与恢复资料，不带全局接口、角色库或世界书库。所有关联在导入时重新映射；备份不含 Key，但会包含私人设定、旧版本、兼容归档及生成快照，请自行保管。新版备份不能导入旧版应用。

## 手动生成与恢复

手机仅在点击生成、回复、重试或生成变体时请求模型。上下文为本作品角色、世界书、启用背景、可知文档、最近 20 轮手机经历及完整待回复输入。不会查询小说。生成启动时固定参考与参与角色，后发言者仅增加自己可见的前序结果；生成中新增消息留给下一轮。必需资料超限会提示调整，不静默截断。

成功子轮独立保存；失败或取消停止后续角色。刷新后可继续未完成部分，不重发成功步骤。历史重写使用原快照，成功才替换旧结果；失败保留原稿。接口继续支持 Chat、Responses、Claude、Gemini、流式输出与取消。

## 示例与验证

交付示例《雨停之前》使用虚构角色及作者绘制场景。锁屏密码为 `0612`；切换到许知，读「书签背面」，再回周屿草稿箱输入 `612` 或 `第612页`。不需要配置接口。

浏览器验证与单元测试使用虚构资料和模拟接口。桌面、390px、360px Chromium 视口验证不代表真实手机硬件或真实模型服务验收。详见 [验证记录](phone-verification.md)。本次没有远端推送或网站发布。
