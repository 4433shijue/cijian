# 此间 3.2 · 互动式角色生成器

在「角色」页点击「帮我补全」，进入新生成器。已有的小说和手机作品仍然独立；生成器只读取你明确提供的创作资料。

## 开始一段访谈

1. 选择「从零创作」「完善已有角色」或「制作 IF 角色」。
2. 写下这次想怎么写，也可以粘贴原卡或一段故事。
3. 填写目标人物的姓名或暂用称呼。想一起完善几个人，先开启「一起完善多位人物」。选择参考资料不会自动增加生成目标。
4. 勾选角色库、世界书库的资料。可搜索、预览；角色参考可标记为改写目标、人物关系参考或风格参考。
5. 点击「确认目标与参考，开始访谈」。只选资料也可以开始，不必再粘贴一遍。

AI 通常每轮提出两三个问题。单选表示互斥方向，多选允许组合；每题可以自定义补充、交给 AI 决定或暂时留白。也可以在「补充想法」中直接写一段话回答。

方向足够明确时会自动成稿；你也可以点击「先生成一版」。之后可以继续描述修改意见，或在结果中手动编辑。卡片仍采用十个维度，资料依据、推测、新增和留白会分别标记。

桌面并排显示问答与参考，结果在下方；窄屏用「对话／设定／结果」切换。通过顶部生成会话列表恢复不同访谈。

## 参考资料和 IF 线

参考角色卡和世界书永远保留原样。生成结果全部另存，不自动改写已创建作品。

开始时保存你勾选资料的快照。之后即使原资料被修改或删除，这次访谈仍使用原快照。要使用新版资料，打开「参考资料与目标」，调整选择后点击「更新参考并开始新修订」。原问答和结果保留供对照，新分支重新确认设定。

生成器以作者视角读取勾选资料，包括其中的秘密。公开简介仍只写对外信息，新角色的完整档案默认私密；世界书的知情范围需要在结果中检查。作者读过不等于所有角色知道。

IF 默认「沿原设定推演」，也可选择「自由 IF 推演」。在「必须保留的角色内核」里写出不可改变的部分。AI 应先讨论核心冲突，成稿会列出保留、改变和变化依据。

## 保存新卡和新世界书

在「结果」中勾选想保存的角色卡和世界书，再点击「将勾选结果另存到库」。新世界书关联了某位目标人物时，需同时勾选那个人物的卡片。保存会一次完成，关联不完整时不会只保存一半。

已经保存的同一结果再次点击不会重复复制。修改或恢复旧版本后会产生新的结果版本，再次保存会新增一张卡。原卡、原世界书和先前保存的卡都不会被覆盖。

编辑内容先自动保存为编辑草稿，点击「保存为新的结果版本」才将其作为后续创作参考。世界书可以调整关联人物和知情范围。没有把握的私密设定应选择「仅作者可见」。

## 专用接口与提示词

顶部「接口设置」默认跟随应用通用接口，也可选择专用接口，单独设置地址、密钥、协议、模型、温度、上下文容量及输出限额。专用配置不会切换其他功能的接口。

支持 Chat Completions、Responses、Claude 和 Gemini。温度沿用所选配置，允许清空使用服务默认值。接口不接受设置时会保留错误，不自动切换接口或重复付费请求。

在应用设置中开启开发者模式，可编辑「访谈与提问」「IF 线推演」「角色卡与世界书成稿」，支持启用、停用和恢复默认。关闭开发者模式只隐藏编辑入口，已启用内容仍然生效。

## 中断、重试与历史

每次请求保存参考、提示词和不含密钥的接口快照。多人卡片按名单依次生成，失败前已经完成的卡片会保留。

在「设定 → 请求记录与恢复」中查看实际请求、原始回复和错误，点击「从此批次未完成处继续」可继续原步骤；已成功部分不会重发。也能编辑原始回复并在本地重新解析。修改接口或提示词后，要使用新设置应发起新请求；历史重试继续沿用原快照。

生成期间可点击停止。关闭窗口时先停止请求，再关闭。刷新或关闭网页后不会自动重启生成；意外关闭留下的会话占用最多约 45 秒后可恢复。不要同时在多个标签页执行同一会话。

修改较早的回答会建立新修订，旧分支保留在历史区，旧结果不再默认加入新请求。必需资料超出上下文容量时，应用会要求调整，不会偷偷删掉参考内容。

## 迁移与备份

本版本为 3.2.0，数据库 13，备份格式 8，兼容导入备份 1～7。

旧版补全草稿、成功卡片、保存关联和未完成输出自动迁入兼容会话。原始草稿仍保留，在「旧版快速补全与恢复」继续使用旧的本地解析功能。迁移不会调用模型，删除已迁入的兼容会话后也不会在下次打开时重复复制。

完整资料库备份包含生成会话、问答、资料快照、结果版本与恢复记录；单本作品备份只包含作品自身资料，不带全局访谈。导入会重新建立编号和关联。删除访谈不会删除已经存入库的新资料。

密钥不写入生成会话、请求快照或导出备份。勾选「仅在此浏览器记住密钥」时，密钥按现有接口设置保存在本地。每条新增存储记录最大 10 MiB；超限或存储失败会提示原因，请保留尚未成功保存的输入。
