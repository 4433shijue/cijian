## 验证边界

文字和图片请求使用受控响应。没有测试用户实际服务商的密钥、账单、CORS、生成速度、参考图能力、人物一致性、真实出图是否遵守自拍规则，以及物理手机浏览器兼容性。没有发生付费生图或自动重试真实请求。

网页直连只实现 Images API 兼容格式；其他原生协议不能仅凭填写 URL 就保证可用。真实服务需要用户配置后使用明确标注会消耗额度的测试图按钮验证。
