# 3.4.3 聊天流式兼容与下载跳转

验证日期：2026-10-25。数据库 16、备份 version 11；原连接恢复快照是可选字段，不含独立 API Key。

- 增加明确点击的「启用聊天流式兼容」入口。仅由标准 Images 路径推导同一服务、同一路径前缀下的 Chat Completions 地址，保留模型与密钥，启用流式并保存。原配置可跨刷新恢复；更换服务、模型、协议或鉴权时清除恢复入口。切换和恢复不调用生图接口，不自动补发失败任务。

- 仅图片下载 GET 跟随 CDN 跳转，全程不携带密钥、Cookie 或来源页面信息。生成 POST 与鉴权查询继续拒绝跳转，并显式省略来源页面信息。
- 全量 659 项单元测试通过，TypeScript 与 Vite 正式构建通过。保留既有静态／动态重复导入提示。
- 正式产物的 18 项浏览器场景均通过，覆盖生图、连接、备份和嵌套弹窗。新增场景验证切换／恢复跨刷新保存且不请求接口，实际 HTTP 服务断线后手动切换、误标 SSE、聊天结束后连接保持打开，以及两个本地服务之间的 CDN 跳转。390px 手机布局截图已检查，无横向溢出。
- 断线模拟发现 Chromium 在服务器关闭空响应连接时可能在网络层重新发送 HTTP 请求。测试分别记录应用 fetch 调用与服务器收到的请求，确认应用失败后没有再次调用 fetch，也没有自动切换端点。应用不自动重试不等于能够禁止浏览器、网关或上游重传，不能保证服务端仅计费一次。

本次使用隔离浏览器、本地 HTTP 服务器和虚构模型响应，未调用真实付费生图接口。公开模型目录标注聊天端点支持不等于已经验证流式返回；用户所用中转站的真实生图、物理 iPad／Safari、上游心跳与实际计费仍未实测。无法从断开的同步请求补回未收到的结果。发布前执行源码白名单与密钥扫描，上线以 Pages 工作流及线上版本核验为准。
