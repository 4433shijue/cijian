## 覆盖范围

- 迁移：旧消息、删除状态、多个版本、双向待回复、失败批次、无消息时的输入草稿、未采用旧草稿、混合来源记忆、重复启动。旧记录兼容归档保留，主线回合与手机回合分开。
- 信息边界：不同故事、他人私聊、群成员加入前后、仅自己可见动态、评论继承受众、删除动态后的评论排除、正文私密段落与正文记忆来源校验。生成期间群成员变化时拒绝过时结果。
- 生成恢复：选定角色串行、失败只重试未完成角色、发送中的下一轮消息、连续超过 20 条待回复输入、停止后迟到结果、重复点击、版本冲突、历史重写的固定参考、部分重写失败后刷新续跑、成功后统一替换与旧版本保留。
- 浏览器操作：机主切换、双方共用会话、手动连续发送、编排、群聊、朋友圈及 AI 评论、点赞、九张本地图片、图片查看、真实 WAV 播放、编辑与版本恢复、主题字号、附件草稿刷新恢复、完整备份与单本备份往返。
- 备份关联：本机与 Worker 两种导入通路，重映射会话、角色、评论、版本、素材、壁纸、附件草稿和生成恢复信息；既有约 100 MB 备份及中止回滚用例通过。
- 导出：当前视角的聊天 PNG、朋友圈九图网格 PNG、超长文本分图 ZIP，以及正文后附独立手机番外的作品导出。

## 重现命令

使用 Node.js 24，在项目目录运行：

```powershell
npm test
npm run test:e2e
npm run build
```

针对手机及受影响流程：

```powershell
node node_modules/vitest/vitest.mjs run tests/phone.test.ts
node node_modules/@playwright/test/cli.js test e2e/chat-batches.spec.ts e2e/phone.spec.ts e2e/journey.spec.ts e2e/reading.spec.ts e2e/round-memory.spec.ts
```
