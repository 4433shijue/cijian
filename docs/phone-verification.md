## 类型与迁移

- 新建故事与新手引导都先选择固定类型；作品内不再切换。角色及世界书选入后保存副本，模板编辑不会同步修改作品。
- 手机与小说的实际生成请求相互隔离；手机只读取本作品的角色、世界书、启用背景、可知文档及手机经历。
- 未标记类型的旧档原子拆分，空侧也保留；检查原小说 ID、正文窗口与回合编号、角色权限、副本编辑及删除独立、重复启动不重复迁移。
- 检查旧版本、删除记录、双向待回复、失败批次、附件草稿、混合来源记忆归档、迁移标识；模拟存储不足验证事务回滚与原档保留。
- 承接背景按原角色知情范围复制，默认启用沿用旧窗口与记忆规则；源小说之后的修改不影响手机。无历史快照的恢复不会加入后来编写的背景与文档。
- 备份 1～5 逐版经过本机与流式导入通路；版本 6 校验作品类型及跨表关联。完整、单本备份往返和约 100 MB 备份、中止导入、Worker 中断恢复均有覆盖。

## 手机与编排

- 私聊、群成员变化、朋友圈受众、评论继承受众、机主私密文档、跨作品附件校验。
- 固定生成快照、串行角色回复、连续待回复输入、生成期间发送下一轮消息、取消、重复点击、失败重试、历史重写与版本冲突。
- 备忘录、照片、剧情草稿的创建、编辑、图片展示、删除及版本恢复；真实编辑草稿与剧情草稿分开。
- 剧本解析、重名角色映射、异常行、原子采用、编排顺序、批量时间、稳定 ID 与受众保留、整次操作撤销。
- 手写及模拟 AI 变体在采用前不进入正式经历；采用时检查源版本。生成变体期间阻止重排与另一轮生成，允许继续发送；取消保留原编排稿。
- 机主切换、连续发送、素材草稿恢复、群聊、朋友圈九图、本地音频、主题字号、聊天及朋友圈 PNG、长内容分图 ZIP 维持回归。

## 阅读与分享

- 开场、锁屏密码、桌面、初始机主与开场切换，正确和错误答案。
- 角色权限先过滤，之后应用解锁条件；跨手机线索、全部或任一条件、循环及缺失依赖检查、通知去重。
- 实际可见内容才记为已读，未滚动到的消息不会提前完成线索；被锁定的消息不会通过引用泄露正文。
- 演出暂停、调速、跳过停顿、重新播放，不创建消息或调用模型；尚未解锁的内容不能通过演出提前打开。
- 阅读包排除作者秘密、生成快照、编辑器草稿、旧版本与未选中内容，选中的本地素材随包保存。
- 相同配置保存保持包版本；阅读进度按包与内容版本隔离。浏览器禁止存储时仍可导出、导入进度文件，错误包版本被拒绝。

## 视觉与生产验证

实际查看了桌面、390px、360px 的创作页、锁屏、手机桌面、聊天、跨手机解谜、浅色及深色主题，并检查照片完整查看、朋友圈与 PNG 长图。没有发现最终截图的横向溢出、文字裁切或图片缺失。

生产验证额外发现并修复了开发环境未暴露的模块循环初始化问题：把依赖数据库的顶层表数组改为调用时读取。之后以构建产物完成导入、阅读预览、离线导出及断网打开。

浏览器回归中还修复了 Windows 开发服务器监听下载临时文件产生 `EBUSY` 的问题，输出目录不再触发文件监听。旧测试中的模式切换、合并导出及默认折叠面板断言已按 3.0 界面更新。最后回归发现批量操作历史按随机 ID 排列，已改为按操作时间排列并复测撤销；新增阅读边界测试发现预览 iframe 禁止表单提交，已放行阅读器自己的解锁表单，预览内解锁、实际阅读与线索触发均通过。

示例 [《雨停之前》](../examples/雨停之前-手机阅读包.html) 使用虚构人物、虚构内容和代码绘制图片。锁屏密码 `0612`；许知的「书签背面」与周屿的草稿构成跨手机线索。它是离线交付物，没有上传至外部服务。
