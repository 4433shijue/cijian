# 此间 3.1 使用与迁移说明

版本 3.1.0，数据库 12，备份格式 7。小说与手机作品继续保持 3.0 的独立结构。本次增加角色自动推进、分工明确的提示词、朋友圈编辑器生成及任务恢复。

## 让故事继续

1. 打开一本手机作品，选择「让故事继续」。
2. 选择由你控制的角色及参与推进的角色。取消再勾选可调整行动顺序。切换手机机主只改变视角，不改变这里的控制权。
3. 设置剧情时间、自由度和导演提示。默认五回合，每回合推进五分钟剧情时间，不必等待五分钟现实时间。
4. 选择直接保存，或先生成到隔离草稿。默认值可保存；「本次临时回合」只影响本次任务。
5. 点击启动。任务栏可以跨页面查看进度、暂停与继续。关闭、刷新或升级后，不会自行恢复请求。

一回合让每位选中且由 AI 控制的角色各获得一次行动机会。只有一个 AI 时，五回合仍有五次机会。角色可以暂不行动，所以行动机会不等于消息数，也不等于请求数。一般先请求行动判断，需要文字时再请求正文；点赞与等待只判断一次。回合数可设 1～100，剧情分钟可设 1～60。可选请求次数上限中，0 表示不额外限制；达到上限会暂停，可以调整后继续。剧情结束时间限制的是行动发生时间。

默认不会替你的角色发送、决定或承诺。只有勾选「全员托管」才允许 AI 使用你的角色。私聊正在等你回复时，角色可以去发朋友圈、写备忘录或处理其他会话。新发出的消息到下一回合才进入参考，已完成任务不会因新消息自动重新启动。

运行中保存的导演提示、角色习惯、参与人选、控制权与自由度从下一回合生效。回合数、保存方式和起止时间等启动参数固定于本任务，修改默认值用于下次任务；本次请求上限可在暂停记录中调整。接口参数与提示词按回合固定，当前步骤重试使用原快照。

## 角色能做什么

私聊一次发送 1～5 条消息，也可以联系本作品已有角色；群聊只使用作者已经建立的群。角色可以发朋友圈、点赞、评论或回复，写自己的备忘录与未发送草稿，记录带知情范围的剧情事件，或者等待。

自动行动不能新建角色、自动建群或改变群成员。只能使用自己已经获准看到的本作品素材；无实际图片时使用文字描述卡，不调用图片或音频生成接口。

「有限创造」默认只允许日常小事；「主动发展」可根据导演提示推进事件和关系。自由度约束剧情权限，接口中的温度控制表达随机性，二者独立。所有请求沿用当前接口的温度设置。

行动习惯包括主动程度、公开表达倾向、新消息延后阅读回合数、朋友圈浏览频率和行动偏好。你可以手填，也可以让 AI 拟定，在确认界面修改后保存。

## 朋友圈两种 AI 用法

「发布动态」中选择角色、填写内容、配图和可见范围：

- 「AI 生成到编辑器」只填入草稿，可继续修改，再点击「发布这条动态」。已选图片保留。
- 「让角色直接发布」生成成功后直接保存动态。
- 「生成记录与恢复」可以继续失败请求、查看接收内容、重新生成，并将未发布的动态草稿重新载入编辑器。
- 已发布动态沿用编辑、删除和历史版本恢复。评论与回复继承原动态受众。

自动推进中的朋友圈遵守任务的保存方式，不会把隔离草稿直接公开到正式朋友圈。

## 提示词编辑

进入设置，打开「显示内部提示词编辑器」，选择手机聊天、角色行动判断、朋友圈发布、朋友圈互动、私密文档、剧情事件推进、对话变体或行动习惯整理。每项可以保存启用、停用、恢复默认。旧的手机聊天自定义文本保留。

关闭开发者模式只隐藏编辑入口，已经启用的文本继续生效。自动任务详情的开发者区域展示每步实际请求、接口参数和参考记录，不显示接口 Key。程序继续校验角色身份、作品归属、受众、附件和允许的操作，提示词不能取消这些校验。

## 恢复、采用和撤销

成功步骤逐个保存。后一步失败、停止或刷新不会重发已完成步骤。暂停会中止当前请求；未完整校验的文字只作为恢复资料，停止后的迟到结果不会写入正式内容。格式错误重试对应阶段，已经成功的行动判断无需再次生成。

隔离草稿中的后续角色，只能读取自己可见的前序草稿。采用整批时再次检查原记录版本，全部检查通过才原子写入。角色、背景、世界书、群成员或被引用内容发生冲突时，保留输出供检查，不覆盖新稿。此时可查看任务中保存的结果，结束旧任务并开始新任务。

运行中允许手写消息、发布动态和保存导演提示。重排、采用变体和整批撤销需先暂停。直接保存的自动批次可以撤销；手工改过的结果、后续评论或引用会阻止撤销。后续自动批次存在依赖时，可明确选择逆序撤销依赖批次；整个过程一起成功或回滚，不连带删除手写内容。文档的旧稿和已生成版本仍保留。

每本作品只允许一个手机生成任务，手动回复、重写、AI 变体及自动推进共用同一任务锁；多标签页不能重复占用。关闭网页后的恢复需要点击继续。首次升级只建立数据和恢复状态，不发送请求。

## 知情与备份

生成只读取本手机作品的角色副本、世界书副本、启用背景、可知文档和事件、最近二十轮已知经历及完整待处理输入，不查询小说。旧历史按原可见范围保留为历史已知；新内容按实际进入请求的情况登记角色阅读。作者查看、读者切换机主和解锁线索不改变角色知识。

完整备份和单本备份包含设置、习惯、任务、逐步快照、角色阅读记录、剧情事件及撤销恢复资料。导入会重映射关联，运行中的任务变为待恢复，不会直接调用模型。兼容旧备份 1～6；缺少作品类型的旧故事仍执行 3.0 的独立拆分。删除作品会停止它的自动请求并清理对应记录。

阅读包仅使用正式采用且允许分享的内容，不包含自动任务、参考快照、接口资料或未采用草稿。阅读包不调用 AI；PNG 与分图 ZIP 导出继续可用。具体旧档拆分规则见 [3.0 说明](phone-upgrade.md)。

## 发布范围

3.0.0 对应独立作品、旧档拆分和六项阅读编排功能；3.1.0 对应角色自动推进、任务恢复和提示词升级。两版保留独立提交、附注标签及 GitHub Pages 部署，不压缩历史。真实模型的角色表现和真实手机设备兼容性需要另行验收；本次自动化验证使用模拟接口和浏览器视口。
