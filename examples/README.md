# 《雨停之前》离线阅读示例

打开同目录的 [雨停之前-手机阅读包.html](雨停之前-手机阅读包.html)。可以断网使用，不需要登录或配置接口。

1. 开场即可切换周屿与许知的手机。锁屏密码是 `0612`。
2. 打开许知的备忘录，阅读「书签背面」。
3. 切回周屿的草稿箱，输入 `612` 或 `第612页`，打开没有发出的消息。
4. 在消息里播放「雨中的对话」，或查看相册和朋友圈。
5. 桌面底部「阅读进度」支持重新开始及进度文件导入、导出。

人物、情节及图片均为虚构。密码属于剧情解谜，HTML 文件没有加密。此文件从 3.0.0 生产构建导出；示例数据可在 `e2e/work-v3.spec.ts` 的 `seedReader` 中找到。
